# Anshdeep Electronics

A bespoke, enquiry-first retail storefront for Anshdeep Electronics in Rajnandgaon, Chhattisgarh.

This repository is being developed on a review branch. Store inventory, prices, promotional claims, financing availability, delivery promises, operating hours, and WhatsApp Business eligibility must be confirmed by the store before publication.

Research and product requirements: see the design and implementation documents in the feature branch.
